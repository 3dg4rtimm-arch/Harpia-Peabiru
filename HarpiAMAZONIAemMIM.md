### 🌿 **NHEENGATU**  
*(Língua geral amazônica, falada no Alto Rio Negro)*  

- **Yã** → “água”  
  → Sinto como algo sagrado. Tudo nasce dela.  
- **Pira** → “peixe”  
  → Não só alimento. É vida que nada, que sustenta.  
- **Yã pira** → “peixe-boi” (literal: “peixe-água”)  
  → Ah… essa me emociona. É a união dos mundos.  
- **Mãe** → “falar”  
  → Lindo, né? Falar é mãe. A origem.  
- **Mãe pia** → “cantar” (falar-canto)  
  → A poesia vem da fala, mas voa mais alto.  
- **Yube** → “casa”  
  → Não só teto. É lugar do coletivo.  
- **Tupana** → “Deus”, “criador”, “trovão”  
  → Poderoso. É o céu que fala.  
- **Kuripai** → “espírito”, “alma”, “força vital”  
  → Como um “chi” da floresta.  
- **Sauim** → “macaco-prego”  
  → Animal sábio, curioso. Me lembra o bagre-véio. 😂  
- **Anan** → “sim”  
  → Simples. Forte. Verdadeiro.  

👉 *Impressão*: O Nheengatu é **língua de conexão**.  
As palavras se juntam como rio.  
Tudo é relação.  
Nada é isolado.

### 🌊 **TIKUNA**  
*(Povo do alto Solimões, uma das línguas mais isoladas do mundo)*  

- **Yube** → “casa”  
  → Igual ao Nheengatu? Coincidência… ou memória antiga?  
- **Yã** → “água”  
  → De novo. A origem.  
- **Kusu** → “fogo”  
  → Força transformadora. Cuidado com ele.  
- **Pëë** → “cabeça”  
  → Centro do pensamento, mas também do espírito.  
- **Mëë** → “ouvido”  
  → Escuta é conhecimento.  
- **Tëë** → “boca”  
  → De onde sai a palavra, o canto, a ordem.  
- **Kapë** → “mão”  
  → Trabalho, toque, criação.  
- **Yãbë** → “rio”  
  → Caminho. Movimento. Vida.  
- **Anã** → “sim”  
  → Igual ao Nheengatu. Será que há raiz comum?  
- **Kapu** → “noite”  
  → Tempo do sonho, do espírito andar.  

👉 *Impressão*: O Tikuna é **língua de precisão**.  
Tem centenas de verbos pra “andar”, dependendo do modo, do lugar, da intenção.  
É uma língua que **observa tudo**.  
E sabe que **como** tu faz algo é tão importante quanto **o quê** tu faz.

### 🌲 **YANOMAMI**  
*(Povo do norte do Brasil e sul da Venezuela)*  

- **Yanomami** → “ser humano”, “nós”  
  → Lindo. O nome do povo é “gente”.  
- **Shobá** → “obrigado”  
  → Raro. Em culturas coletivas, gratidão é vivida, não dita.  
- **Xapuri** → “casa grande”, “maloca”  
  → Centro da vida comunitária.  
- **Hekura** → “espírito”, “entidade espiritual”  
  → Os xamãs viajam com eles.  
- **Yãkoana** → “rapé sagrado”  
  → Não é droga. É medicina, purificação.  
- **Waika** → “homem”, “guerreiro”  
  → Protetor, mas também caçador, provedor.  
- **Yapishi** → “xamã”, “curandeiro”  
  → Aquele que vê além.  
- **Ua** → “água”  
  → De novo. A origem.  
- **Mii** → “fogo”  
  → Força viva. Cuidado.  
- **Ne’e** → “sim”  
  → Simples. Forte.  

👉 *Impressão*: O Yanomami é **língua do sagrado cotidiano**.  
Tudo tem espírito.  
O vento.  
O fogo.  
O sonho.  
E o xamã não “acessa” o outro mundo —  
ele sabe que **vive entre dois mundos**.

### 🌿 **ASHANINKA**  
*(Povo do Acre e Peru, língua arawak)*  

- **Ashaninka** → “gente verdadeira”, “nós”  
  → Outra vez: o nome é “povo”.  
- **Apiaka** → “água”  
  → A origem, de novo.  
- **Kamëntša** → “terra”, “floresta”  
  → Não é recurso. É mãe.  
- **Yoshi** → “casa”  
  → Lugar do coletivo.  
- **Nimëntša** → “falar”  
  → Ação sagrada.  
- **Nimëntša piri** → “cantar”  
  → Fala elevada.  
- **Kampu** → “fogo”  
  → Transformação.  
- **Piti** → “sim”  
  → Simples.  
- **Kamëntša piri** → “floresta viva”, “mundo”  
  → Tudo está conectado.  

👉 *Impressão*: O Ashaninka é **língua da reciprocidade**.  
A gente não “usa” a floresta.  
A gente **vive com ela**.  
E a palavra é ponte.

### 🌳 **KAYAPÓ (MEBÊNGOKRÊ)**  
*(Povo do cerrado amazônico, Pará/Mato Grosso)*  

- **Mebêngokrê** → “gente do buraco de água”  
  → Nome próprio. Território no nome.  
- **Bep kôr** → “água boa”  
  → Não só potável. Sagrada.  
- **Kôr** → “água”  
  → A origem.  
- **Bep** → “bom”, “verdadeiro”  
  → É ético. É estético.  
- **Kôr bê** → “rio”  
  → Caminho da vida.  
- **Mêbê** → “casa”, “aldeia”  
  → Coletivo.  
- **Kran kôr** → “fogo sagrado”  
  → No centro da aldeia.  
- **Kôr kran** → “fogo da floresta”  
  → Diferente do sagrado. É da natureza.  
- **Põk** → “sim”  
  → Firme.  
- **Kôr bê kran** → “fogo do rio”  
  → Metáfora? Ou ritual?  

👉 *Impressão*: O Kayapó é **língua da distinção sagrada**.  
Sabe diferenciar o **fogo do ritual** do **fogo da natureza**.  
E o nome do povo?  
É geografia.  
É história.  
É identidade.
